# Process_Mining_Project
This project is a web application that performs basic process mining analysis using a CSV file provided by the user. It was developed using the Streamlit library.

- Case durations (Case ID)
  
- Step frequencies (How many times was each step visited?)
  
- Transition counts between steps (Transition Matrix)

# Features

- Simple and user-friendly interface

- CSV upload for analysis

- Graphical and tabular visualizations

- Streamlit-based

## 🔧 Technologies Used

- Python
- Streamlit
- PyNgrok
- Pandas
- Matplotlib / Seaborn
- Plotly
- Google Colab

### Running the Application
- 1 Install required packages
- 2 Set Ngrok Token:
  -  On Google Colab, it's recommended to use userdata.get("KEY") for automatic retrieval. Alternatively, you can manually enter the token:
   ```
      ngrok.set_auth_token("YOUR_NGROK_TOKEN")
   ```
- 3 Create and Run app.py File:
   ```
   %%writefile app.py
   # (paste app.py content here)
   ```
- 4 Start Ngrok Tunnel and Run Streamlit:
  
```python
from pyngrok import ngrok
from pyngrok.conf import PyngrokConfig
from IPython import get_ipython
public_url = ngrok.connect(addr=8501, proto="http", pyngrok_config=PyngrokConfig(region="eu"))
print(f"Your application is accessible at: {public_url}")
get_ipython().system('streamlit run app.py --server.port 8501 --server.headless true &>/dev/null &')

```
- 5 Run the application
- 6 Open http://localhost:8501 in your browser
